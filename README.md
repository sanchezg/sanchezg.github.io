# Gonzalo’s personal page

A notebook-style homepage for GitHub Pages, built with plain HTML and CSS. No build step or external dependencies. Supports mobile layouts and automatic light/dark appearance.

## Content

- Edit the introduction and biography in `index.html`.
- The résumé links directly to the PDF in the `sanchezg/cv` repository, so updates there are reflected without copying a file here.
- Add or edit projects in `.project-list` in `index.html`, with a link and a one-sentence description for each.
- Update colors and spacing in `styles.css`.

## Local preview

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

## Hosting

Publish the repository root with GitHub Pages. No package installation or build command is required.
